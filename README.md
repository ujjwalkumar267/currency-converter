# 💱 Currency Converter

A simple and responsive **Currency Converter web application** that uses an external API to fetch exchange rates and convert amounts between different currencies.

## 🚀 Features

* Convert an amount from one currency to another
* Fetches exchange rates using an external API
* Supports multiple currencies
* Simple and user-friendly interface
* Responsive design
* Displays the converted amount instantly
* Handles user input and API responses

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and API integration
* **Exchange Rate API** — Fetching currency exchange rates

## 🔌 API Integration

The application sends a request to the currency exchange API and processes the returned JSON data to calculate and display the converted amount.

### Basic Flow

```text
User enters amount
        ↓
Select source currency
        ↓
Select target currency
        ↓
Application calls Currency API
        ↓
API returns exchange rate
        ↓
Converted amount is displayed
```
